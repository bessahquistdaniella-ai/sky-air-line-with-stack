# Sky Airways Reservation System — Stack Assignment

This project preserves the Sky Airways reservation website and adds a Stack Demo to demonstrate the Last-In, First-Out (LIFO) data structure.

## Run
Open `index.html` in a modern browser. Flight results and prices are simulated; reservations are stored in browser local storage.

## Stack demo
Use Push, Pop/Undo, Peek, Load Sample Actions, and Clear Stack to demonstrate stack operations. The demo illustrates an undo-history stack; it does not actually undo a real reservation.

## Queue/stack assignment note
The added demonstration is a stack (LIFO): the last action pushed is the first one popped.
